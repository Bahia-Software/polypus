The native QML API now rejects samples with zero features. `qml.Dataset`,
`Model.fit`, `TrainedModel.predict` / `run`, `Model.circuit` /
`TrainedModel.circuit`, `qml.expval` / `qml.jacobian` / `qml.vjp` and
`qml.kernel_matrix` raise a `ValueError` (a `polypus.ConfigurationError` where
the entry point already raised one) saying that every sample needs at least one
feature, where they used to run a model that never saw the data and predicted a
constant. The amplitude encoder gets that message too, instead of the
zero-norm one. Fewer features than qubits stays accepted (contract C-11, #513).
