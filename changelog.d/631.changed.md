**BREAKING:** `polypus.qml.Ansatz.conv(..., pairing="odd_pairs")` below three
active qubits is now a `ValueError` at the call: there is no odd pair to act
on, so no gate read the parameters it reserved. `qml.load` and unpickling
refuse a saved model with such a layer. To keep using one, delete the layer
from its `spec` and, for a saved trained model, also delete its 4 (`"basic"`)
or 3 (`"cartan"`) entries from `params`, the ones right after the parameters
of the layers before it: left in, `load` fails on the parameter count, and
deleting others shifts the values every later layer reads. Those entries were
never read, so the model computes what it computed before. A convolution below
two active qubits keeps raising `ValueError`, with a message that now names
the convolution and its pairing (#631).
