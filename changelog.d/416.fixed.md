On Windows the gate-parallel calibration is now cached under
`%LOCALAPPDATA%\polypus\` when `XDG_CACHE_HOME` is not set. PowerShell and cmd
define neither `XDG_CACHE_HOME` nor `HOME`, so the first native simulation of
every process measured the threshold again and never saved it.
`XDG_CACHE_HOME` still wins on every platform, and macOS and Linux are
unchanged. A Windows user who has `HOME` set and an existing cache in
`%HOME%\.cache\polypus\` measures once more, in under a second;
`calibrate_parallel_threshold()["cache_path"]` shows the new location (#416).
