The `documentation` link of the `polypus` crate, and the site's and README's Rust API links, point at docs.rs, which keeps the API of each release; the rustdoc on the site under `/rust/`, built from `main`, is linked as the unreleased API. For contributors, a root `justfile` holds every check CI runs and CI calls its recipes, so `just ci` reproduces them locally (`just ci-all` adds the MSRV, dependency-floor, packaging, semver, fuzz and Miri jobs); optional pre-commit hooks run rustfmt, ruff and nbstripout.
