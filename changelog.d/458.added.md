`polypus.log_to_python()` forwards the Rust core's log records to Python's `logging`, as an alternative to `polypus.init_logger()` (only one of the two can be installed per process). Each record goes to the logger named after the Rust module that emitted it under `polypus` (`polypus_optimizers::util` to `polypus.optimizers.util`), so `logging.getLogger("polypus")` sets the level, handlers and format of everything Polypus logs. Records carry the Rust file and line, the levels are read from Python at the start of each call, a disabled record never takes the GIL, and an `ERROR` or `WARNING` record emitted while the interpreter is shutting down goes to stderr as one fixed line instead of being lost (#458).
