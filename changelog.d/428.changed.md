**BREAKING:** on Linux, a native circuit of 31 to 40 qubits is no longer
refused with the qubit ceiling's `ValueError` / `polypus.NativeCircuitError`:
it runs if the memory budget holds it and raises
`polypus.InsufficientMemoryError` (not a `ValueError`) otherwise. Above 40
qubits, and above 30 where no memory limit is detected, the ceiling error is
unchanged. For Rust users, `polypus_sim::MAX_QUBITS` is 40 instead of 30, so
`StatevectorSimulator::default()` and `Statevector::new` accept up to 40
qubits; the 30-qubit fallback ceiling is
`polypus_backend::mem_budget::FALLBACK_MAX_QUBITS` (#428). The parallelism
calibration cache keeps reading existing files as before.
