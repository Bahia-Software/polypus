native QML API (`shots`, `n_qpus`, `nodes`, `cores_per_qpu` or `seed` of
`Model.fit`, `TrainedModel.predict`/`run`, `qml.expval`, `qml.jacobian`,
`qml.vjp` and `qml.kernel_matrix`, and the `seed` of
`Dataset.train_test_split`): `shots=True` was read as `1` (and `False` as
`0`); it is now a `TypeError`, before any backend exists, as the counts of
the native API and `final_shots` already were (#607).
