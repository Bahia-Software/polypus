The exact native path (`exact=True`) kept the map of probabilities of circuits it only reads for a few expectation values: an exact gradient of `qml.train` or `Model.fit` held one map per circuit of the gradient until the step ended (one per shifted circuit for the parameter-shift fallback, so on a dense output it needed far more memory than the adjoint gradient it replaces), the exact fitness one per circuit of a candidate window, the exact `qml.expval`, `qml.jacobian` and `qml.vjp` one per circuit of a block, and `TrainedModel.predict(exact=True)` one per row. Each circuit is now read as soon as its probabilities are computed and only its expectation values are kept, which also makes exact training faster; every result is unchanged, bit for bit. `TrainedModel.run(exact=True)` and the exact kernel, which return or read the probabilities themselves, are unchanged (#645).
