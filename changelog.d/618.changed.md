`polypus-logger` uses `jiff` instead of the unmaintained `chrono`
(RUSTSEC-2026-0543) for its local timestamps; the log line prefix, the JSON
`"timestamp"` field and the default log file name keep their format. For Rust
users, the minimum supported versions rise to `log` 0.4.21 (every workspace
crate) and `serde` 1.0.221 (the crates that use it), the floors `jiff`'s
optional dependencies need (#618).
