Wheels are now published for CPython 3.14 on Linux x86_64, macOS on Apple
Silicon and Windows x64, and CI runs its latest-Python legs on 3.14. CPython
3.14 on Linux aarch64 still has no wheel: qiskit-aer 0.17, which Polypus
requires, publishes none there, so pip builds both Polypus and qiskit-aer
from their source distributions (#624).
