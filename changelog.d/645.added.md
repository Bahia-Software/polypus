For Rust users: `NativeStatevectorBackend::run_circuits_exact_with` reads each circuit's exact probabilities as soon as they are computed and keeps only what the reader returns; `QmlProblem::read_probabilities`, `fitness_from_expectations`, `gradient_from_expectations` and `adjoint_runs_from_expectations`, `ExpectationJacobian::jacobian_from_expectations` and `JacobianBlock::jacobian_from_expectations` take those readings instead of the probability maps, with the same results bit for bit; `ExpectationJacobian::model` returns the model it differentiates (#645).
