`polypus.torch.QuantumLayer(model, *, initial_params=None, seed=None, ...)`,
a `torch.nn.Module` over a native `qml.Model` for hybrid quantum-classical
networks: forward = `qml.expval` over the batch, backward = one `qml.vjp`
call with the incoming gradient (parameters, inputs or both; #559), so
it trains with any `torch.optim` optimizer; float32 networks work as is (the
computation is float64 on the CPU; a complex input is a `TypeError`, #602),
and a `seed` derives one per backend call so a training replays.
`polypus.torch.from_trained(trained, ...)` starts one from a `TrainedModel`.
PyTorch is the new optional extra `pip install "polypus-quantum[torch]"`
(`torch>=2.14.1,<3`); `import polypus` does not import it (#502). See
`examples/qml_torch_hybrid.py`.
