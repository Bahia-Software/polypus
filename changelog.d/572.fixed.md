A native QML model whose size fit in 64 bits but no circuit could hold was
accepted by its builder and only failed later, out of memory or time, in
`circuit`, `bind` or `fit`: `Ansatz(2).hardware_efficient(2**40)` built,
and so did a `hardware_efficient(reps, rotations=[])` on two or more qubits,
with no parameters but `reps` blocks of entanglers.
`Ansatz(2**40).real_amplitudes(0)` aborted the process on a failed
allocation, `Ansatz(2**62).real_amplitudes(0)` raised a `PanicException`,
and so did `Encoder(64).amplitude_encoder()`. All are now a `ValueError` at
the call, which leaves the object as it was, and so is a saved file edited
to such a model. On a single active qubit, where it emits no gate at all, a
`hardware_efficient(reps, rotations=[])` is still accepted, and building its
circuit no longer takes time in `reps` (#572).
